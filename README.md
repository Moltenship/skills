# skills

Personal agent skills, installable with the [skills CLI](https://skills.sh).

## Install

```sh
npx skills add Moltenship/skills
```

Or a single skill:

```sh
npx skills add Moltenship/skills --skill html-plan
```

## Skills

| Skill | Description |
| --- | --- |
| [html-plan](skills/html-plan/SKILL.md) | Create human-readable plans as standalone HTML pages, styled strictly after [vercel.com/design.md](https://vercel.com/design.md), with copy cleaned by the [unslop](https://github.com/cursor/plugins) skill. |
